# pyrothermo – thermochemistry engine

`pyrothermo` computes heat capacity, enthalpy, entropy and Gibbs energy of pure species from NIST Shomate coefficients, and ΔH°, ΔS°, ΔG° and K for reactions. Projects 02–04 in this repository build on it.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev,app]"
```

## Data

| File | Contents | Source |
| --- | --- | --- |
| `data/species.yaml` | Shomate coefficients per temperature range | NIST Chemistry WebBook (fits from Chase 1998, NIST-JANAF 4th ed.) |
| `tests/data/janaf_reference.csv` | `species,T,Cp,S,H_minus_H298` (J/mol·K, J/mol·K, kJ/mol) | NIST-JANAF tables |
| `tests/data/janaf_formation.csv` | `species,T,dfH,dfG` (kJ/mol) for compounds | NIST-JANAF tables |
| `data/raw/` | The saved source pages these were read from | webbook.nist.gov, janaf.nist.gov (accessed 2026-11-04) |

Both data files are **generated by code** from the saved source pages. Nobody types the numbers in, so each value can be traced back to `data/raw/`:

```powershell
bash scripts/fetch_sources.sh                               # re-download sources (optional)
.\.venv\Scripts\python.exe -I scripts/build_reference_data.py   # rebuild yaml + csv
```

The build script only decides which NIST columns to use. For Fe it also sets where to switch between NIST's separate α-δ and γ fits: α below 1184 K, γ from 1184 to 1665 K, δ from 1665 to 1809 K, then liquid. Those switch-over temperatures come from JANAF table Fe-003.

**Graphite is the one exception.** The WebBook has no Shomate fit for C (graphite), so `scripts/fit_graphite.py` fits one to the JANAF C-002 table:

- Cp is fitted by least squares over two ranges, 298.15–1000 K and 1000–4000 K.
- H and S are pinned to JANAF at 298.15 K and kept continuous at 1000 K.

These coefficients are this project's fit, not NIST's, and `species.yaml` says so. Graphite is checked against the same table it was fitted to, so that check measures the quality of the fit (better than 0.07 %), not independent agreement.

### Validation against JANAF
55 reference rows at temperatures from 298.15 to 3000 K: 48 agree within 0.1 % in Cp, S and H − H298. The other 7 are deviations in the NIST fits themselves. They are listed with reasons in `tests/test_reference_data.py`, as expected failures:

- **Fe at 1000 and 1100 K (α-iron near the Curie point, 1042 K):** the NIST fits don't join up in H, by up to 0.37 kJ/mol. S at 1100 K is 0.5 % off.
- **Fe at 1700 and 1800 K (δ-iron):** Cp is 0.14–0.23 % high.
- **Fe2O3 at 500 K:** Cp is 0.11 % low.
- **Fe2O3 and Fe3O4 at 298.15 K:** the rounded NIST coefficients give H − H298 = −0.026 and −0.007 kJ/mol at 298.15 K, where it should be exactly 0.

**Reactions:** the formation ΔH° and ΔG° of FeO, Fe3O4, Fe2O3, CO, CO2 and H2O, calculated from the elements, were compared with JANAF's tabulated values in 24 rows from 500 to 2000 K. 21 agree within 0.05 kJ/mol, most within 0.01 kJ/mol. The 3 exceptions are the iron oxides at 1000 K, where the α-Fe fit error carries through at about 0.35 kJ/mol per Fe atom (`tests/test_formation.py`).

## Usage

```python
import numpy as np
from pyrothermo import load_species, Reaction

db = load_species()  # data/species.yaml
db["Fe2O3"].cp(1000.0)  # J/(mol K)
rx = Reaction.from_string("Fe2O3 + 3 CO = 2 Fe + 3 CO2", db)
rx.dG(np.array([900.0, 1200.0])), rx.K(1200.0)  # J/mol, dimensionless
```

Temperatures are always in K. Results are in SI units (J, mol, K). Both scalars and NumPy arrays are accepted.

## Interface

```powershell
streamlit run app/streamlit_app.py
```

The app has three tabs:

- **Species:** Cp, H − H298, H, S and G against T, with phase changes marked.
- **Reaction:** ΔG° and log₁₀ K against T, plus values at a single temperature.
- **Molar mass:** composition and molar mass of a formula.

Before real data exists, a sidebar toggle shows the clearly labelled **fake** test data so you can try the interface.

## Conventions

- `H(T) = ΔfH°298 + (H(T) − H298)`, where `H − H298` is measured from the phase present at 298.15 K. Above a phase change it therefore includes the latent heat, as JANAF does.
- At a temperature exactly on a range boundary, the lower range is used.
- A temperature outside the listed ranges raises `TemperatureRangeError`. Nothing is extrapolated.
- In YAML, mark a real phase change with `transition: true` on the range below it. The continuity test then allows H to jump there.
- Atomic weights are the CIAAW abridged standard atomic weights (2024), from https://www.ciaaw.org/abridged-atomic-weights.htm, accessed 2026-11-04.

## Limitations

- Pure species in their standard states only: pure condensed phases and ideal gases at 1 bar. There are no solutions, activities or slag models.
- Accuracy is limited by the NIST Shomate fits; see the validation section above for where they differ from JANAF.
- The NIST H2O(g) fit starts at 500 K, so reactions involving water vapour are only available from 500 K.
- Wüstite is treated as stoichiometric FeO if that is how it is entered.
- There are no kinetics. K tells you whether a reaction can proceed, not how fast.
